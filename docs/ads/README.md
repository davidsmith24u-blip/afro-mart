# Afro Mart ads

Campaign preparation for afromartz.biz.

| File | Purpose |
|---|---|
| `campaign-plan.md` | Budget, audiences, campaign structure and decision rules |
| `ad-copy.md` | Meta, Google and TikTok copy, headlines and scripts |
| `access-and-tracking.md` | Ad-account access, pixel/tag setup and UTM convention |
| `creatives/` | Ready-to-upload square, story, banner and carousel images |

Regenerate the creatives with:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\ads-creatives.ps1
```
